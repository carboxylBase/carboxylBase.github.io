AC 自动机的精髓在于 fail 指针的含义, fail 指针和实际存在的匹配边共同组成一张有向图, 然后我们可以在这张图上做一些 dp 之类的事情.

值得注意的是不一定是 DAG !!! 一个显然的反例是 aaaaaa 这种单字符形成的字符串.

我们举例说明 acam 的 fail 指针的实际含义.

比如现在有模式串 abc, bcd, cd, 如果我们当前匹配出 abc, 下一个字符为 d, 那么我们发现 abcd 是不存在的, 则考虑 abcd 的最长存在的后缀, 不难发现是 bcd, 于是这里的失配指针就指向 bcd 所代表的节点.
