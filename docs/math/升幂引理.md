设 $p$ 为质数，$n$ 为非零整数。定义 **$v_p(n)$** 为 $n$ 的质因数分解中质数 $p$ 的最高指数。

> **示例：**
> * $v_2(8) = 3$ （因为 $8 = 2^3$）
> * $v_3(18) = 2$ （因为 $18 = 2^1 \cdot 3^2$）
> * $v_p(1) = 0$ （对任意质数 $p$）

## 当 $p$ 为奇素数时

### 减法形式
设 $p$ 是奇素数，$x, y$ 是整数，且满足：
1. $p \mid x - y$
2. $p \nmid x$ 且 $p \nmid y$

对于任意正整数 $n$，等式成立：
$$v_p(x^n - y^n) = v_p(x - y) + v_p(n)$$

### 加法形式
设 $p$ 是奇素数，$x, y$ 是整数，且满足：
1. $p \mid x + y$
2. $p \nmid x$ 且 $p \nmid y$

当 **$n$ 为奇数** 时，等式成立：
$$v_p(x^n + y^n) = v_p(x + y) + v_p(n)$$

## 当 $p = 2$ 时

由于 $2$ 的幂次性质较为特殊，其结论需根据 $n$ 的奇偶性分类讨论（前提均为 $x, y$ 是奇数）：

### $n$ 为奇数
若 $2 \mid x - y$，$2 \nmid x$，$2 \nmid y$，则：
$$v_2(x^n - y^n) = v_2(x - y)$$
$$v_2(x^n + y^n) = v_2(x + y)$$

### $n$ 为偶数
若 $2 \mid x - y$，$2 \nmid x$，$2 \nmid y$，则：
$$v_2(x^n - y^n) = v_2(x - y) + v_2(x + y) + v_2(n) - 1$$
$$v_2(x^n + y^n) = 1$$

> **补充：** 在 $p=2$ 且 $n$ 为偶数的情况下，如果满足更强的条件 $4 \mid x - y$，公式可简化为 $v_2(x^n - y^n) = v_2(x - y) + v_2(n)$。

应用举例: $v_2(5^k - 1) = 2 + v_2(k)$.
