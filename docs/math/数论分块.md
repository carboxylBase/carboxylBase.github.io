## 向上取整的数论分块

向下取整的数论分块是常见的, 众所周知的, 显而易见的, 向上取整的其实可以变换成向下取整的形式.

$$
\lceil \frac{x}{a} \rceil = \lfloor \frac{x - 1}{a} \rfloor + 1
$$

后面无需多言.

## 数论分块套数论分块

对于形如下面形式的代码:

```cpp
int n; cin >> n;
for (int l=1,r;l<=n;l=r+1) {
    int m = n / l;
    r = n / (n / l);
    for (int x=1,y;x<=m;x=y+1) {
        y = m / (m / x);
        // do something
    }
}
```

循环本身的复杂度是 $O(n^{3/4})$ 的, 其复杂度分析和杜教筛的一致.
