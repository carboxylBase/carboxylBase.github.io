## 二维闵可夫斯基和的定义

算法竞赛中通常只讨论二维情形下两个凸包的闵可夫斯基和.

给定两个平面图形 \(P, Q \subset \mathbb{R}^2\)，它们的**闵可夫斯基和**定义为
\[
P \oplus Q = \{\, p + q \mid p \in P,\ q \in Q \,\}.
\]
即：将 \(P\) 中的每个向量与 \(Q\) 中的每个向量逐点相加所得到的所有向量的集合。

二维闵可夫斯基和也可从几何角度定义。固定图形 \(Q\)，让图形 \(P\) 在平面上平移，并要求 \(P\) 与 \(Q\) 至少有一个交点。此时，取 \(P\) 上某一指定点，记录该点在所有允许平移位置中可能到达的全部位置，其轨迹集合正是 \(P\) 与 \(Q\) 的闵可夫斯基和。

不难发现这个定义和上面的定义是等价的.

## $O(nm\log(nm))$ 的做法

主包在 2025ICPC沈阳G 中独立发现了这个做法, 感觉还挺直观的, 但是会的人似乎并不多.

从第二定义出发，考察 $P$ 上某指定点 $x$ 的所有可能位置。可以发现，随着 $P$ 在 $Q$ 上平移，$x$ 的运动轨迹本身也构成一个凸包。因此只需枚举该凸包的所有可能顶点。

进一步观察可知，只有当 $P$ 的某个顶点与 $Q$ 的某个顶点重合时，$x$ 的位置才可能成为其轨迹的一个顶点。于是，我们将 $P$ 与 $Q$ 的顶点逐一配对，枚举得到至多 $nm$ 个候选点，对这些点求一次凸包，即可得到 $x$ 的完整轨迹，也即 $P \oplus Q$。
